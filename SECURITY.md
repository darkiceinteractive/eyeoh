# Security policy

## Supported version

Security fixes are made against the latest published release and the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put users at risk. Contact Dark Ice Interactive through [darkice.au](https://darkice.au/) with the affected version, reproduction steps, impact, and any suggested mitigation.

We will acknowledge a report, investigate it, and coordinate disclosure. This project does not offer a bug bounty.
